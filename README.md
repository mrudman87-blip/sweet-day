# «Сладкий день» — лендинг кондитерской

**Демо:** https://mrudman87-blip.github.io/sweet-day/

Одностраничный сайт для кондитерской с тортами на заказ: каталог, шаги заказа, отзывы, FAQ и форма
заявки, которая приходит владельцу в Telegram.

## Что внутри

- **Чистый HTML/CSS/JS** без фреймворков и библиотек: сайт быстро грузится и просто поддерживается.
- **Адаптивная вёрстка** от телефона до широкого монитора, «резиновая» типографика (`clamp()`).
- **Светлая и тёмная тема** по настройке устройства (`light-dark()`).
- **Анимации при прокрутке** на CSS (scroll-driven animations), с учётом настройки «уменьшить движение».
- **Мобильное меню** на Popover API, FAQ на `<details>`, окно «Спасибо» на `<dialog>`.
- **Картинки AVIF/WebP/JPG** в нескольких размерах (`<picture>` + `srcset`): главная картинка весит 33 КБ.
- **SEO:** мета-теги, Open Graph-превью для мессенджеров, микроразметка Schema.org (Bakery).
- **Форма → Telegram** через `send.php`: маска телефона, проверка на сервере, защита от спам-ботов
  (honeypot), ограничение частоты, экранирование ввода. Токен бота хранится только на сервере.

> На GitHub Pages форма работает в демо-режиме, потому что здесь нет PHP. На хостинге заказчика
> заявки уходят в Telegram.

## Установка на хостинг с PHP 8+

1. Загрузить файлы в корень сайта.
2. Скопировать `config.example.php` в `config.php` и вписать токен бота и chat id.
3. Готово: `.htaccess` закрывает `config.php` от просмотра из браузера.
